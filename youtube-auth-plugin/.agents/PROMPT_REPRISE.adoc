== Session 004 (TERMINÉE) — Session navigateur isolée

* Défaut réel : `BrowserLauncher` ouvrait l'URL de consentement dans le
  navigateur par défaut. Sur une machine dont le profil Chrome est déjà connecté
  à un autre compte Google, Google répondait avec ce compte → refresh token
  attaché à la mauvaise chaîne.
* Correctif : `ChromiumLaunchCommand` (pur) construit un argv avec
  `--user-data-dir=<profil neuf>`, `--no-first-run`, `--no-default-browser-check` ;
  `BrowserExecutableResolver` auto-détecte Chrome/Chromium/Brave/Edge/Vivaldi
  (Linux/macOS/Windows) ; `BrowserLauncher` lance le binaire avec un profil neuf
  par défaut, supprimé après succès. Repli navigateur par défaut = dernier recours
  + avertissement.
* DSL : `youtubeAuth.browserExecutable`, `youtubeAuth.browserProfileDir`,
  `youtubeAuth.freshBrowserProfile` (défaut `true`).
* Tests : 3 unit (`ChromiumLaunchCommand`, `BrowserExecutableResolver`,
  `BrowserLauncher` via seams) + 1 scénario BDD (`youtube_auth.feature`).
* Version locale `0.0.2 → 0.0.4` (JitPack `v0.0.4` ; le tag `v0.0.3` a échoué
  sur l'installation SDKMAN de JitPack).
* Local = Build : `compileKotlin`/`compileTestKotlin`/`compileFunctionalTestKotlin`
  + `ktlintCheck` + `validatePlugins` VERTS. Tests délégués à la CI.
