== État

Module `youtube-auth-plugin` (dans le dépôt `video-kernel-gradle`) : plugin
`education.cccp.video.auth` fournissant la tâche `obtainYouTubeRefreshToken`
(flux OAuth 2.0 loopback → écrit le refresh token dans un `youtube.yaml`
gitignoré). Version **0.0.2** (non publiée). Domaine pur `video.auth` (consent
URL, parseur de jeton, réécriture du fichier) + seams N2 injectables.

Le dogfooding réel a été exécuté par le pilote : `youtube.yaml` existe côté
hyperframes et capsule. Il a révélé puis fait corriger le défaut loopback
(requête sans `code`/`error` terminant l'attente).
