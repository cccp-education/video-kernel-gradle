(capsule/reveal.js et hyperframes/Watts, ce dernier en **production** depuis S-018).

=== Garde de stabilité d'API — `capsule.ci.KernelApiSurface` + `KernelApiStabilityTest`

- `KernelApiSurface` (objet de test, réflexion pure — zéro dépendance `kotlin-reflect`) :
  * `typeNames()` — les **12 types** exportés (`capsule.kernel.*` + `.segment.*`) ;
  * `functionNames(type)` — les méthodes publiques non-getter (ports) ;
  * `getterNames(type)` — les getters de propriétés (`getX`), synthétiques filtrés
    (`componentN`, `copy`, `copy$default`, `equals`/`hashCode`/`toString`).
- `KernelApiStabilityTest` (4 tests) verrouille : l'ensemble des **types**, les
  contrats des ports **`VideoEngine`** (`name`/`isAvailable`/`render`/`close`) et
  **`SegmentSource`** (`name`/`segments`), et les **propriétés** des 8 data classes
  du modèle. Toute rupture exige une édition délibérée du manifeste.
