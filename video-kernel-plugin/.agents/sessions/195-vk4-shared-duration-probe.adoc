== Décision d'architecture (cadrage `CADRAGE_EPIC_VK_SHARED_PORTS.adoc`)

Le cadrage S-021 avait exclu TTS/audio/sous-titres du noyau en confondant
**ports** et **implémentations**. Décision : le noyau héberge les **ports**
(fun interfaces pures) ; les **implémentations** (binaires externes) restent N2.
La garde `video.ci.KernelBoundaryAudit` interdit `processbuilder`/`org.gradle`
dans le noyau → une implémentation ffprobe ne peut pas y vivre ; seul le port +
un parseur pur y vivent. Critère « second consommateur » (≥ 2 moteurs) : pas
d'abstraction spéculative.

== Gates

- **Local = Build** : `compileKotlin` + `compileTestKotlin` VERTS.
- **Tests = CI** : suite `test` exécutée en CI après push.
- **Correctif CI (run `38512503267`)** — la CI a révélé un défaut du manifeste
  d'API : `KernelApiSurface.publicMethods` ne filtrait pas les méthodes
  **privées** non synthétiques ; le lambda de `FfprobeDurationParser.parse`
  génère `parse$lambda$0` (`ACC_PRIVATE, ACC_STATIC, ACC_FINAL`, **non**
  `ACC_SYNTHETIC`) qui fuyait dans la surface gelée. Fix : filtre
  `Modifier.isPublic` (le manifeste gèle la surface **publique** uniquement).
  Le défaut est **révélé par la CI** (règle Local = Build, Tests = CI) — il ne
  pouvait pas l'être localement sans lancer les tests.
