== Contexte

La roadmap de video-kernel n'avait **pas** de traçabilité EPIC pour la grammaire
des notes d'orateur : `HF-SPEAKER-NOTES` (hyperframes, cadré S-049) promouvait
cette grammaire au noyau, mais `US-1` n'existait ni dans le portefeuille
`INDEX.adoc` ni dans `BACKLOG.adoc` (seulement dans `PROMPT_REPRISE`). Cette
session crée l'EPIC côté noyau et consomme sa première US.

_Décision de doctrine_ : factorisation « à 2 » (amendement S-195) — capsule
consomme déjà la grammaire `[NOTE.speaker]`, hyperframes devient le 2ᵉ
consommateur. Le noyau héberge la **grammaire**, jamais le mapping scène/slide.

'''

== Livré

* `video.kernel.notes.SpeakerNoteBlock` — paire `(title, text)`, invariants
  non-blancs.
* `video.kernel.notes.SpeakerNoteBlockParser` — grammaire configurable :
  - `headingLevel` (défaut `2`, `== `), les niveaux plus profonds ne sont pas
    des sections ;
  - `noteMarker` (défaut `[NOTE.speaker]`), un marqueur avec attributs
    (`[NOTE.speaker,role="x"]`) est accepté ;
  - bloc délimité `--` ;
  - parité legacy avec l'adaptateur capsule : note avant toute section ignorée,
    corps blanc ignoré, **la première note sous une section gagne**, note non
    fermée émise en fin d'entrée.
* Manifeste d'API : `KernelApiSurface` +2 types ; `KernelApiStabilityTest`
  renommée `frozen at 0_9_0` + assertions `SpeakerNoteBlock` (getters) et
  `SpeakerNoteBlockParser` (`parse`).
* `version = 0.9.0` (source ; **non publiée**).

== Incident de session (transparence)

avec un one-liner `python3` (violation de la contrainte globale « Zéro Python »).
