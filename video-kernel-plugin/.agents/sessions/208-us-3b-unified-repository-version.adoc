== Mission

distinctes (`video-kernel 0.9.1` sans préfixe, `youtube-auth-plugin v0.0.4`/`0.0.5`

un tag ne pouvait pas servir les deux artefacts de façon cohérente.

  sous-builds au même tag ; les branches legacy (`0.9.1`, `0.8.0`, `0.7.x`,
  `0.0.4/0.0.5`) sont conservées pour que les anciennes coordonnées restent
  résolvables.

* Commit `1f5628c`, tag annoté **`0.9.2`** (sans préfixe), push `main` + tag.
