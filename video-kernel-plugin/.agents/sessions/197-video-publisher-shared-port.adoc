== Décisions

* **Placement N1** (pas N0 `contracts`) : capacité **vidéo** partagée par les
  moteurs, même logique que les ports VK-4.
* **Factorisation doctrine « à 2 »** (amendement S-195) : `VideoDescriptionComposer`
  factorise `capsule.publish.VideoDescriptionBuilder` +
  `capsule.chapters.YouTubeChaptersFormatter` (adoption capsule = US-3).
* **Frontière noyau préservée** : aucun HTTP, aucun `ProcessBuilder`, aucun
  vocabulaire plateforme. L'adaptateur OAuth/upload reste N2 (D3 — pas de SDK Google).
* **Contrat non-jetable** : `VideoPublicationResult` sealed, aligné sur les ports
  VK-4 (dégradation propre).
