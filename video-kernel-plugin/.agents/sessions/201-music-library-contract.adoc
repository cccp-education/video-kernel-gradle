== Mission

US-2 de l'EPIC **HF-MUSIC-LIBRARY** (hyperframes S-050) : porter au noyau le
**contrat musical neutre** partagé par le producteur (newpipe) et les
consommateurs (hyperframes, capsule) — modèle, sélection déterministe et
**séquence sonore** déclarée dans l'AsciiDoc.

== Constat

Le noyau n'avait aucun modèle de musique : chaque moteur aurait dupliqué le
manifeste, la sélection et la validation des cues. Le seuil de factorisation
« à 2 » (S-195) est atteint (hyperframes + capsule).

== Livré (package `video.kernel.music`)

* `MusicLicence` — énumération **fail-closed** (`OWN`, `CC0`, `CC_BY`,
  `ROYALTY_FREE`, `LICENSED`, `UNKNOWN`) + `parse` tolérant (casse/`_`/`-`) +
  `requiresAttribution` (CC-BY).
* `MusicTrack` — modèle du manifeste (id, titre/artiste, fichier, sha256,
  durée, licence, source, attribution, tags, mood, énergie) + invariants ;
  `isUsable()` exige une licence déclarée **et** un fichier.
* `MusicLibrary` — jeu de pistes + `schemaVersion`, `find`, `usable`, `byMood`.
* `MusicSelection` + `MusicTrackSelector` — sélection **déterministe et sans
  LLM** : id explicite (inconnu/inutilisable → rejet, jamais de substitution),
  sinon mood, sinon première piste utilisable (ordre par `id`).
* `SoundCue` — cue neutre déclaré dans le document (scène, track/mood, volume,
  fondus, boucle, arrêt) + invariants (`volume 0..1`, fondus ≥ 0, track|mood|stop).
* `SoundSequence` + `SoundSequenceValidator` — séquence ordonnée ; rejette
  **avant rendu** (piste inconnue, licence inutilisable, mood sans piste, cue
  dupliqué par scène) ; `stop` toujours valide.
