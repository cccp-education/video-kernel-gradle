== Mission

Extraire au noyau N1 les **briques pures** de l'adaptateur de publication
YouTube dupliquées à l'identique entre capsule et hyperframes (doctrine
« à 2 »), sans y faire entrer le réseau (reste N2). Décision pilote 2026-10-31 :
Règle 2 « accord toujours granted ».

== Livré (additif `0.6.0 → 0.7.0`)

Package `video.kernel.publish` :

* `ChapterLineParser` — parseur de chapitres (identique aux deux moteurs) ;
* `YouTubeCredentials` — modèle OAuth 2.0, `toString` rédigé (jamais de secret) ;
* `YouTubeCredentialsLoader` — lecture `youtube.yaml` sans dépendance YAML ;
* `YouTubePublishCommand` — **réécrit sans Jackson** (JSON construit/parsé
  manuellement, échappement testé) pour respecter la frontière du noyau ;
* `DisabledVideoPublisher` — publication dégradée sans réseau ;
* `PublishHttpRequest`, `PublishHttpResponse`, `HttpTransport` — seam HTTP pur.

Restent N2 (par moteur) : `JdkHttpTransport` (`java.net.http`) et
`YouTubeDataApiPublisher` (séquencement réseau) — le noyau porte le contrat, pas
l'implémentation (doctrine VK-4).
