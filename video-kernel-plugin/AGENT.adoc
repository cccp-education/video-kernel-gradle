== Principe

`video-kernel` extrait le **noyau neutre** de `capsule-gradle` (EPIC
`CAP-ENGINE-DECOUPLING`, US-5). Il porte le modèle de production vidéo
(`VideoKind`/`VideoSegment`/`VideoScript`/`VisualSource`/`VideoProductionEntry`/
`VideoProductionPlan`) et les **ports** (`VideoEngine`, `SegmentSource`), **sans
aucun couplage** à un moteur de rendu (reveal.js, Playwright, AsciiDoc) ni à
Gradle. Un second moteur (HyperFrames) peut l'implémenter.

  `java.`/`kotlin.`/`contracts.` ; jamais `slide`/`deck`/`reveal`/`playwright`

  en local ; les tests s'exécutent en CI.
